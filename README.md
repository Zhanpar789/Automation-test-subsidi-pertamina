# Automation Test Subsidi Pertamina

## 📌 Background

Project ini dibuat untuk membantu proses pelaporan penjualan LPG subsidi pada aplikasi Subsidi Tepat Pertamina.

Sebelumnya, proses pelaporan dilakukan secara manual dengan cara menyalin (copy-paste) Nomor Kartu Keluarga (KK) satu per satu dari file Excel ke aplikasi Subsidi Pertamina. Ketika jumlah data pelanggan cukup banyak, proses ini menjadi repetitif, memakan waktu, dan berpotensi menimbulkan kesalahan input.

Untuk mengatasi hal tersebut, saya membuat automation testing menggunakan Cypress yang dapat mengotomatisasi proses input data KK ke dalam aplikasi, sehingga proses pelaporan menjadi jauh lebih cepat dan efisien.

Project ini digunakan secara nyata untuk membantu operasional usaha keluarga saya dalam melakukan pelaporan penjualan LPG subsidi.

---

## 🚀 Features

* Login otomatis ke aplikasi Subsidi Pertamina.
* Membaca daftar Nomor Kartu Keluarga (KK) yang telah disiapkan.
* Melakukan input data KK secara otomatis.
* Mengurangi pekerjaan manual yang berulang.
* Mempercepat proses pelaporan penjualan LPG subsidi.
* Mengurangi risiko human error saat memasukkan data.

---

## ⚙️ How It Works

1. Siapkan daftar Nomor Kartu Keluarga (KK) dari file Excel.
2. Salin seluruh data KK ke file `Example.feature`.
3. Jalankan automation test menggunakan Cypress.
4. Script akan melakukan proses input data secara otomatis ke aplikasi Subsidi Pertamina.
5. Pengguna hanya perlu memantau proses berjalan hingga selesai.

---

## 🛠️ Tech Stack

* Cypress
* JavaScript
* Cucumber (BDD)

---

## 📈 Benefits

Dengan automation ini:

* Waktu pelaporan menjadi jauh lebih singkat dibandingkan input manual.
* Tidak perlu lagi melakukan copy-paste KK satu per satu.
* Proses dapat dijalankan secara konsisten dan berulang.
* Membantu meningkatkan produktivitas dalam operasional harian.
